At a glance

Goal. A local, read-only web app that shows every pod run across your repos: each run's stage, the current wave's slices, what needs you, and each engineer's live activity. Phase 1 of docs/master-plan.md; actions such as merging come in phase 2.

What shipped. A pnpm workspace with three packages (model, server, web), three-OS CI with a secret scan, and three screens: the runs list and pipeline, the wave board, and the engineer view. A Node server on 127.0.0.1 reads pod docs, Claude Code transcripts, port claim files, and read-only gh calls, and pushes the board to the browser over server-sent events.

Instead of: merging and queue answers now.
