Gaps

  • No browser-only option returns an absolute path (spec).
  • The Windows dialog can open behind the browser. Fix: a TopMost owner form (2016 write-up, maybe stale).
  • Linux may have no dialog tool; wrappers return an empty list (README).
  • Not verified: code-server, qBittorrent, Portainer, JupyterLab UI behaviour.

Best practices

  • Check Host header for localhost, 127.0.0.1, [::1], and still authenticate (NCC, 2018).
  • Put listing behind the API key, as Syncthing and Radarr do.
  • List folders only by default.
  • Treat cancel and "no dialog tool" as separate results.

Ideas, minimal to bold

1. Autocomplete

Keep the text box; add /api/fs/list (folders only).

2. pod-docs flag

Mark listed folders that contain pod-docs.

3. Folder browser panel

Breadcrumbs, drives, up button.

4. Browse button (Windows)

POST /api/fs/pick runs PowerShell; falls back to the panel.

5. Smart start folder

Parent of existing repos, then home, then drives.

6. Scan a parent

Find all subfolders with pod-docs; "add all".

7. Mac and Linux dialogs

osascript, zenity, kdialog behind a capability check.
