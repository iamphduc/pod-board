What's different from the last draft

  • Dark first, with a near-black page and white text. Light still works from the ⋯ menu.
  • Geist and Geist Mono replace Bricolage Grotesque, Instrument Sans and JetBrains Mono. Both are open fonts the board can host itself.
  • No colored card edges. State is a small dot plus a word, so it never relies on color alone.
  • About twice the space: 24 px inside cards, 40 px between sections, and a narrower main column on desktop.
  • The primary button is white on black (black on white in light), the way Vercel does it, instead of blue.
