Calm dashboard: how it fits together

Goal: make screen 1 calm. When you open it, you see in a couple of seconds what pod needs from you, if anything, and how to do it, and everything else is one click away. The whole board moves to a dark-first, black-and-white look in the style of Vercel, and "+ Repo" picks a folder from a folder browser. One sprint: calm-screen.

Main flow

sequenceDiagram
  actor You
  participant Page as Runs screen
  participant Next as Next step
  participant API as Server
  You->>Page: open the board
  Page->>Next: selected run's model data
  Next-->>Page: most urgent item (e.g. merge PR #78)
  Page-->>You: Next step card with one button
  You->>Page: press Merge, confirm
  Page->>API: existing merge action (token, Host, Origin)
  API-->>Page: what GitHub reports
  You->>Page: + Repo
  Page->>API: GET folder listing (token, Host)
  API-->>Page: subfolders, pod-docs marks
  You->>Page: click down to the folder, Add
  Page->>API: POST /api/repos (existing)

Data

config.json doesn't change. The browser keeps pod-board-theme (nothing stored now means Dark) and a new key for the open tab. The folder listing reads folder names only, stores nothing, and never reads file contents.
