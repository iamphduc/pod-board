Pod Board

Plan

Four phases, each usable on its own

Phase 1 · build nowSee every run

Read-only. Runs list, pipeline, wave board, live transcripts. Can't break a run.

Phase 2 · build nowApprove from the board

Merge wave PRs, answer queue entries, reply continue or go. Each click does what you'd type in chat.

Phase 3 · decide laterStep into an engineer

Engineers run as their own sessions. Phone ping when a run needs you.

Phase 4 · decide laterRuns without a chat

A runner starts your own claude with your login. Billing rules for this changed three times in 2026.
